# 蓝色大肥鱼 · 冬装

名称、描述和历史宠物 ID 见 `素材清单.json`。原导出记录将冬装保存为独立宠物；线上选中状态未在本次整理中查询。

- `spritesheet.png`：从当前创作素材构建的透明精灵图，1536 × 2288。
- `逐帧PNG/`：从当前构建的精灵图导出的 73 张 192 × 208 透明单帧。
- `预览/`：与常服统一的 12 个 GIF，包含九个动作、全动作总览、16 方向循环及待机 → 悬停吃饭 → 待机过渡。
- `contact-sheet.png`、`directions.png`：动作与方向总览。
- `创作素材/`：角色三视图 `三视图.jpg`、基础造型、动作源图、原生成请求和任务记录。
- `验证/`：当前构建记录、文件校验值与本地检查报告。

悬停交互沿用吃白米饭，对应标准 `jumping` 行。精灵图、逐帧 PNG、两张总览和全部预览均由当前创作素材重新构建；输入与输出校验值见 `验证/构建记录.json`。旧质量及方向语义报告不再描述当前派生文件，已交由 Git 历史保存。

布局与创建步骤见 [项目说明](../README.md)。
